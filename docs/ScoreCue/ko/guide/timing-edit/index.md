<p class="warning"><strong>곡 진행 편집은 자동 넘김 설정에서 가장 중요한 단계입니다.</strong> 자동 분석은 편집할 초안을 만드는 기능이며, 악보의 모든 마디와 기호를 완벽하게 판별한다고 보장할 수 없습니다. 자동 분석 뒤에는 이 화면에서 마디 경계와 실제 연주 순서를 반드시 확인하세요.</p>

## 편집 화면 열기

악보를 열고 빈 곳을 탭한 뒤, 왼쪽 위 퀵 메뉴의 <strong>악보 속성</strong>을 엽니다. 동기화 영역에서 <strong>악보 진행 편집</strong>을 선택합니다.

편집 화면에는 다음 정보가 함께 표시됩니다.

- **마디 영역과 번호**: ScoreCue가 한 마디로 판단한 범위입니다.
- **기호 배지**: 반복, 점프, 템포 등 현재 마디에 적용된 진행 정보입니다.
- **상단 편집 도구**: 마디를 선택하면 나누기, 합치기와 기호 도구가 나타납니다. 화면이 좁으면 옆으로 밀어 나머지 도구를 확인합니다.
- **진행 요약**: 분석된 실제 연주 순서를 `1–8 → 1–8 → 9`처럼 보여 줍니다. 기호를 수정할 때 이 순서도 함께 확인합니다.
- **페이지 이동**: 여러 페이지를 앞뒤로 이동하며 페이지 경계의 마디도 점검합니다.
- **실행 취소**: 마지막 교정 하나를 되돌립니다.

## 먼저 알아둘 기본 조작

### 마디 선택과 기호 편집

수정할 마디의 안쪽을 탭하면 마디가 선택되고 상단에 편집 도구가 나타납니다. 이미 추가된 기호 배지를 탭하면 값을 바꾸거나 삭제할 수 있습니다.

기호가 보이는 위치보다 <strong>그 기호가 어느 마디에 적용되어야 하는지</strong>가 중요합니다. 예를 들어 `D.S. al Coda`는 글자가 인쇄된 마디의 끝에서 실행되므로 그 마디를 선택해 지정합니다.

### 나누기

실제 두 마디가 하나의 긴 영역으로 인식되었을 때 사용합니다.

1. 빠진 마디선이 있어야 할 위치를 정확히 탭합니다.
2. 상단의 <strong>나누기</strong>를 누릅니다.
3. 새로 생긴 두 마디의 번호와 경계를 확인합니다.

탭한 지점이 곧 새 경계가 됩니다. 경계 가까이에 너무 좁은 조각이 생기지 않도록 마디 안쪽을 정확히 탭하세요.

### 합치기

하나의 실제 마디가 둘로 잘못 나뉘었을 때 사용합니다.

1. 둘 중 <strong>앞 마디</strong>를 선택합니다.
2. 상단의 <strong>합치기</strong>를 누릅니다.
3. 선택한 마디와 바로 다음 마디가 하나로 합쳐졌는지 확인합니다.

다른 줄이나 다음 페이지의 영역과도 이어질 수 있으므로, 페이지 끝에서 합칠 때는 다음 페이지의 첫 마디가 실제로 같은 마디인지 특히 주의하세요.

### 마디선 위치 조절

마디 수는 맞지만 경계선이 음표 중간이나 옆 마디까지 걸쳐 있을 때는 마디선을 좌우로 끕니다. 이 작업은 마디의 박 수를 바꾸지 않고 화면에 표시되는 경계 위치만 바로잡습니다. 마디 수 자체가 틀렸다면 드래그가 아니라 <strong>나누기</strong> 또는 <strong>합치기</strong>를 사용해야 합니다.

## 기호 하나씩 이해하기

| 도구 | 뜻과 적용 위치 | ScoreCue에서의 동작 |
|---|---|---|
| **𝄆** | 도돌이 시작. 반복할 구간의 첫 마디에 지정 | 나중의 `𝄇`에서 이 마디로 돌아옵니다. 시작 기호가 없으면 곡의 첫 마디를 반복 시작으로 봅니다. |
| **𝄇** | 도돌이 끝. 반복 구간의 마지막 마디에 지정 | 기본적으로 구간을 두 번 연주합니다. `xN`이 있으면 지정한 횟수를 따릅니다. |
| **1.** | 볼타, 즉 1번·2번·3번 엔딩 | 선택한 번호와 같은 반복 회차에만 그 마디를 연주합니다. 괄호가 여러 마디에 걸치면 그 안의 모든 마디에 같은 번호를 지정합니다. |
| **𝄋** | 세뇨(Segno). D.S.의 목적지 | `D.S.`를 만나면 점프 지점 앞의 가장 가까운 세뇨로 돌아갑니다. |
| **𝄌** | 코다(Coda). 코다 구간의 시작점 | `D.C./D.S. al Coda`로 되돌아간 뒤 `→𝄌`를 통과하면 이곳으로 이동합니다. |
| **→𝄌** | To Coda. 코다로 빠져나가는 지점 | 처음 통과할 때는 그대로 진행하고, `al Coda` 점프 후 다시 통과할 때만 코다로 이동합니다. |
| **Fine** | 곡의 종료 지점 | `D.C. al Fine` 또는 `D.S. al Fine`으로 되돌아온 뒤 이 마디에서 곡을 끝냅니다. |
| **D.S.** | 되돌이 점프 도구 | `D.C.`, `D.C. al Fine`, `D.C. al Coda`, `D.S.`, `D.S. al Fine`, `D.S. al Coda` 중 하나를 선택합니다. 선택한 마디의 끝에서 실행됩니다. |
| **♩=** | 템포 변경 | 인쇄된 기준 음표와 BPM을 입력합니다. 선택한 마디부터 다음 템포 변경 직전까지 적용됩니다. |
| **4/4** | 박자표 변경 | 분자와 분모를 지정합니다. 선택한 마디부터 다음 박자 변화 직전까지 적용되며 마디 시간과 카운트 계산에 사용됩니다. |
| **xN** | 명시된 반복 횟수 | `𝄇`이 있는 반복 끝 마디에 지정합니다. 2회부터 16회까지 설정할 수 있습니다. |
| **𝄐** | 늘임표(페르마타) | 선택한 마디 끝에 유지할 박 수를 추가합니다. 기본 2박이며 기호 배지를 눌러 1~16박으로 바꿀 수 있습니다. |
| **rit.** | 리타르단도, 점점 느리게 | 선택한 마디 안에서 현재 BPM부터 입력한 목표 BPM까지 서서히 느려집니다. 이후에는 다음 템포 지시까지 목표 BPM을 유지합니다. |
| **accel.** | 아첼레란도, 점점 빠르게 | 선택한 마디 안에서 입력한 목표 BPM까지 서서히 빨라지고, 이후에는 다음 템포 지시까지 그 BPM을 유지합니다. |
| **a tempo** | 원래 템포로 복귀 | 선택한 마디부터 곡 첫 마디에 설정된 템포와 기준 음표로 돌아갑니다. |

### D.C.와 D.S. 선택 항목

- **D.C.**: 곡 처음으로 돌아간 뒤 끝까지 연주합니다.
- **D.C. al Fine**: 곡 처음으로 돌아가 `Fine`에서 끝냅니다.
- **D.C. al Coda**: 곡 처음으로 돌아가 `To Coda`에서 `Coda`로 이동합니다.
- **D.S.**: `Segno`로 돌아간 뒤 끝까지 연주합니다.
- **D.S. al Fine**: `Segno`로 돌아가 `Fine`에서 끝냅니다.
- **D.S. al Coda**: `Segno`로 돌아가 `To Coda`에서 `Coda`로 이동합니다.

<p class="note">점프 기호와 목적지 기호는 한 세트입니다. `D.S.`에는 `𝄋`, `al Fine`에는 `Fine`, `al Coda`에는 `→𝄌`와 `𝄌`가 모두 있어야 합니다. 하나라도 빠지면 의도한 순서로 진행되지 않습니다.</p>

## 자주 쓰는 진행 예제

### 1~8마디를 두 번 연주한 뒤 9마디로 진행

1. 1마디에 `𝄆`를 지정합니다.
2. 8마디에 `𝄇`를 지정합니다.
3. 진행 요약이 `1–8 → 1–8 → 9…` 형태인지 확인합니다.

악보에 도돌이 시작이 생략되어 있다면 8마디의 `𝄇`만 지정해도 곡 처음부터 반복됩니다.

### 1번·2번 엔딩

예를 들어 7~8마디가 1번 엔딩이고 9~10마디가 2번 엔딩이라면 다음처럼 설정합니다.

1. 반복 시작 마디에 `𝄆`를 지정합니다.
2. 7마디와 8마디에 각각 `1.`을 지정하고, 도돌이 끝이 있는 8마디에 `𝄇`를 지정합니다.
3. 9마디와 10마디에 각각 `2.`를 지정합니다.
4. 진행 요약에서 첫 회차는 7~8마디, 두 번째 회차는 9~10마디를 지나는지 확인합니다.

### D.S. al Coda

1. 되돌아갈 위치의 마디에 `𝄋`를 지정합니다.
2. 코다로 빠져나갈 위치의 마디에 `→𝄌`를 지정합니다.
3. 코다 구간이 시작되는 마디에 `𝄌`를 지정합니다.
4. `D.S. al Coda` 문구가 있는 마디에 `D.S.` 도구를 누르고 <strong>D.S. al Coda</strong>를 선택합니다.
5. 진행 요약이 D.S. 마디에서 세뇨로 돌아간 뒤 To Coda를 거쳐 코다로 이동하는지 확인합니다.

## 자동 분석 결과는 이 순서로 검토하세요

1. **페이지와 단 확인**: 모든 악보 줄이 위에서 아래, 왼쪽에서 오른쪽 순서로 잡혔는지 봅니다.
2. **마디 수 확인**: 누락된 마디선은 나누고, 음표 기둥이나 글자를 마디선으로 오인한 곳은 합칩니다.
3. **마디 경계 확인**: 경계 위치만 어긋난 곳은 마디선을 끌어 맞춥니다.
4. **박자와 템포 확인**: 첫 박자·첫 템포와 곡 중간의 변경 지점을 모두 확인합니다.
5. **도돌이와 볼타 확인**: `𝄆`, `𝄇`, 1·2번 엔딩, `xN`을 실제 악보와 대조합니다.
6. **점프 기호 확인**: D.C.·D.S., Segno, Fine, To Coda, Coda가 빠짐없이 연결되는지 봅니다.
7. **표현 기호 확인**: rit., accel., a tempo, 페르마타의 목표 BPM과 유지 박 수를 확인합니다.
8. **진행 요약 확인**: 표시된 마디 순서를 소리 내어 악보와 대조합니다.
9. **실제 재생 확인**: 곡 처음부터 끝까지 한 번 재생하고, 반복과 페이지 전환을 확인합니다.

## 증상별 빠른 해결

| 증상 | 먼저 확인할 곳 | 해결 방법 |
|---|---|---|
| 한 마디 안에서 다음 마디로 너무 늦게 넘어감 | 두 마디가 하나로 인식되었는지 | 빠진 마디선 위치에서 **나누기** |
| 음표 중간에서 마디가 바뀜 | 하나의 마디가 둘로 인식되었는지 | 앞 영역을 선택해 **다음 마디와 합치기** |
| 마디 수는 맞지만 강조 영역이 비뚤어짐 | 마디선의 화면 위치 | 경계선을 좌우로 드래그 |
| 반복을 한 번만 연주함 | 반복 끝 `𝄇` 누락 | 마지막 마디에 `𝄇` 추가 |
| 1번 엔딩을 두 번째에도 연주함 | 볼타가 괄호 전체에 지정되었는지 | 1번 엔딩의 모든 마디에 `1.` 지정 |
| D.S. 뒤에 곡 처음으로 이동함 | `𝄋` 누락 또는 잘못된 위치 | D.S.보다 앞선 실제 세뇨 마디에 `𝄋` 추가 |
| al Coda인데 코다로 가지 않음 | `→𝄌` 또는 `𝄌` 누락 | 출발점과 목적지를 모두 지정 |
| Fine에서 곡이 끝나지 않음 | 점프 종류가 단순 D.C./D.S.인지 | `al Fine` 종류를 선택하고 Fine 지정 |
| 곡 뒤로 갈수록 일정하게 어긋남 | 시작 BPM·기준 음표 | `♩=` 값과 점4분음표 등 기준 음표 확인 |
| 특정 마디부터 어긋남 | 중간 템포·박자 변화 | 변화가 시작되는 마디에 `♩=` 또는 박자표 추가 |

<p class="tip">기호를 하나 수정할 때마다 진행 요약을 확인하면 문제를 빠르게 찾을 수 있습니다. 복잡한 곡은 도돌이와 볼타를 먼저 맞춘 뒤 D.C.·D.S.와 코다를 추가하세요.</p>

## 저장 전 최종 점검

- 첫 마디와 마지막 마디가 빠지지 않았는가
- 페이지 끝과 다음 페이지 첫 마디가 잘못 합쳐지거나 나뉘지 않았는가
- 반복 회차와 1·2번 엔딩의 실제 연주 순서가 맞는가
- D.C.·D.S. 점프 뒤 Fine 또는 Coda에서 올바르게 끝나는가
- 템포와 박자 변화가 정확한 마디에서 시작되는가
- 페르마타와 rit./accel. 구간의 시간이 실제 연주와 자연스러운가
- 자동 넘김이 연주자가 다음 페이지를 읽을 수 있을 만큼 여유 있게 작동하는가

<p class="warning">편집 뒤에는 오른쪽 위 <strong>저장</strong>을 누르세요. 저장 전에 뒤로 나가면 마지막 수정이 반영되지 않을 수 있습니다.</p>
