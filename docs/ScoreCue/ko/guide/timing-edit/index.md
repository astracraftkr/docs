## 편집 화면 열기

악보를 열고 빈 곳을 탭한 뒤, 왼쪽 위 퀵 메뉴의 <strong>악보 속성</strong>을 엽니다. 동기화 영역에서 <strong>악보 진행 편집</strong>을 선택합니다.

편집 화면에서는 마디를 선택한 뒤 상단 도구로 기호, 나누기, 합치기를 조정하고 경계선을 직접 끌어 위치를 맞출 수 있습니다.

## 기본 조작

- **마디 탭**: 수정할 마디를 선택합니다.
- **경계선 드래그**: 인식된 마디의 시각적 위치를 조절합니다.
- **나누기**: 하나로 인식된 두 마디를 분리합니다.
- **합치기**: 잘못 나뉜 마디를 하나로 합칩니다.
- **기호 변경·삭제**: 반복, 페르마타 등 진행에 영향을 주는 기호를 보정합니다.
- **스텝 목록 편집**: 시간 순서, BPM, 구간 길이를 숫자로 확인합니다.

## 특정 부분만 늦거나 빠를 때

1. 미리보기로 문제가 시작되는 마디를 찾습니다.
2. 해당 스텝의 BPM 또는 길이를 확인합니다.
3. 앞뒤 마디가 자연스럽게 이어지도록 작은 값부터 조절합니다.
4. 저장한 뒤 문제 구간보다 한두 마디 앞에서 재생해 다시 확인합니다.

## 템포 변화 표현하기

곡 중간에 템포가 바뀌면 새로운 구간을 만들고 해당 지점의 BPM을 지정합니다. 점점 빨라지는 **accelerando**나 느려지는 **ritardando**는 시작과 끝 템포를 기준으로 변화 구간을 설정합니다.

긴 음이나 쉼이 있는 **페르마타**는 실제 머무를 시간을 반영해야 합니다. 자동 분석 값만으로 부족하면 해당 스텝의 시간을 늘립니다.

<p class="note">악보 속성의 **기본 연주 속도**는 전체 진행을 비율로 빠르게 또는 느리게 만듭니다. 곡 전체가 같은 비율로 어긋날 때는 개별 마디를 고치기 전에 이 값을 먼저 조절하세요.</p>

## 저장 전 점검

- 첫 마디와 마지막 마디가 빠지지 않았는지
- 반복 구간이 의도한 순서로 진행되는지
- 박자 변화 뒤 카운트인이 올바른 박 수를 사용하는지
- 페이지 전환이 연주자가 읽기 좋은 만큼 앞서는지

<p class="warning">편집 뒤에는 오른쪽 위 <strong>저장</strong>을 누르세요. 저장 전에 뒤로 나가면 마지막 수정이 반영되지 않을 수 있습니다.</p>
