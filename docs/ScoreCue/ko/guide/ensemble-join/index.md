## 주변 세션 찾기

<ol class="task-list">
  <li>홈의 <strong>합주 → 참여하기</strong>를 누릅니다.</li>
  <li>Android가 요청하면 주변 기기·Bluetooth 권한을 허용합니다.</li>
  <li><strong>주변 세션</strong> 목록에서 호스트가 알려 준 이름을 선택합니다.</li>
  <li>암호가 있는 세션이라면 전달받은 암호를 입력합니다.</li>
  <li>자신의 이름과 파트를 확인하고 참여합니다.</li>
</ol>

세션이 자동으로 보이지 않으면 호스트의 세션 코드를 입력하거나 목록을 새로고침합니다. Wi-Fi만으로도 참여할 수 있지만, 자동 검색에는 주변 기기 권한이 필요할 수 있습니다.

## 로그인하지 않은 상태

일반 세션 참여는 로그인 없이 가능합니다. 세션 창에 표시되는 **로그인하기** 버튼을 누르면 바로 계정 화면으로 이동할 수 있습니다. 밴드 멤버 전용 세션은 멤버 확인을 위해 로그인해야 합니다.

## 내 파트 악보 연결

호스트가 곡을 바꾸면 내 기기에서 같은 곡에 해당하는 파트 악보를 선택합니다. 예를 들어 호스트가 `곡 A`를 열었을 때 나는 `곡 A - 베이스.pdf`를 연결할 수 있습니다.

- 연결은 파일명이 같을 필요가 없습니다.
- 마디 수가 크게 다르면 경고가 표시될 수 있습니다.
- 악보가 없다면 메신저 등으로 미리 전달받아 기기에 추가한 뒤 연결합니다.
- 곡이 바뀔 때마다 매핑된 악보가 자동으로 열립니다.

## 준비와 재생

악보를 연결하고 페이지를 확인한 뒤 **준비**를 누릅니다. 호스트가 시작하면 카운트인, 템포, 시작 마디와 페이지 진행이 함께 움직입니다. 호스트가 허용한 세션에서는 참여자도 시작·정지를 요청할 수 있습니다.

## 같은 계정 중복 참여 제한

같은 계정으로 로그인한 두 기기는 하나의 세션에 동시에 참여할 수 없습니다. 한 계정으로 여러 자리를 차지하는 악용을 막기 위한 제한입니다. 다른 연주자는 각자의 계정으로 로그인하거나, 일반 세션에서 로그인 없이 참여해야 합니다.

## 무료 사용 시간

무료 플랜은 하루 첫 세션 진입 시점부터 30분 동안 합주를 사용할 수 있습니다. 실제로 연주한 시간만 합산하는 방식이 아니며, 세션에서 나가도 그날의 30분 창은 계속 흐릅니다. 남은 시간은 세션 화면에 표시됩니다.

## 연결이 끊겼을 때

ScoreCue는 약 30초 동안 자동 재연결을 시도합니다. 악보는 계속 볼 수 있으므로 즉시 앱을 닫지 말고 기다리세요. 실패하면 같은 네트워크, 호스트 세션 상태, 권한을 확인한 뒤 다시 참여합니다.

<p class="warning">공연 전에는 모든 기기의 앱 버전을 맞추고, 절전 모드와 배터리 최적화가 Wi-Fi·Bluetooth를 끊지 않도록 확인하세요.</p>
