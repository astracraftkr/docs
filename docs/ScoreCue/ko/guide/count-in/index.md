## 카운트인 기본값 설정

<ol class="task-list">
  <li>홈 오른쪽 위의 <strong>설정</strong>을 엽니다.</li>
  <li><strong>연주</strong> 탭에서 <strong>카운트인 기본값</strong>을 찾습니다.</li>
  <li><strong>끔</strong> 또는 1~4마디 중 원하는 길이를 선택합니다.</li>
</ol>

이 값은 곡별 설정이 없는 악보에 적용됩니다. 예를 들어 4/4 악보에서 2마디를 고르면 총 8박을 센 뒤 재생이 시작됩니다. 3/4 악보라면 총 6박입니다.

## 특정 곡만 다르게 설정

1. 악보를 열고 빈 곳을 탭합니다.
2. 왼쪽 위의 조절 아이콘을 눌러 <strong>악보 속성</strong>을 엽니다.
3. 재생 영역의 <strong>카운트인 (이 곡)</strong>에서 0~4마디를 선택합니다.

곡별 값을 지정하면 전역 기본값보다 우선합니다. 빠르게 시작해야 하는 곡은 끄고, 시작 음을 준비해야 하는 곡은 2마디로 두는 식으로 사용할 수 있습니다.

## 카운트인에만 메트로놈 사용

연주 중에는 클릭을 듣고 싶지 않지만 시작 템포는 필요하다면 설정의 <strong>카운트인에만 메트로놈</strong>을 켭니다. 카운트인이 끝나면 메트로놈은 멈추고 악보 진행만 계속됩니다.

<p class="note">카운트인의 템포와 박 수는 재생을 시작하는 위치 바로 뒤의 악보 진행 정보를 사용합니다. 곡 중간의 다른 박자에서 시작하면 해당 구간에 맞춰 셉니다.</p>

## 소리가 들리지 않을 때

- 미디어 음량이 0이 아닌지 확인합니다.
- 오디오 출력이 Bluetooth 기기로 연결되어 있는지 확인합니다.
- 악보 진행에 올바른 BPM과 박자가 있는지 확인합니다.
- 설정에서 카운트인이 **끔**으로 되어 있지 않은지 확인합니다.

<p class="tip">합주 세션에서는 호스트가 지정한 시작과 카운트인이 모든 참여자에게 동기화됩니다. 개인 악보의 카운트인은 준비 상태 확인용으로만 생각하세요.</p>
