<p class="warning"><strong>자동 분석 결과는 완성본이 아니라 편집을 위한 초안입니다.</strong> ScoreCue는 마디선, 박자, 템포, 도돌이표와 진행 기호를 최대한 찾지만 악보의 인쇄 상태와 배치에 따라 놓치거나 다른 요소로 오인할 수 있습니다. 자동 분석 후에는 반드시 <a href="{{ '/ScoreCue/ko/guide/timing-edit/' | relative_url }}">곡 진행 편집</a>에서 직접 살펴보세요.</p>

## 자동 분석 시작

홈의 악보 카드에서 <strong>악보 진행 만들기</strong>를 누르거나, 뷰어의 상단 퀵 메뉴에서 <strong>악보 속성 → 자동 생성</strong>을 선택합니다. 분석이 끝날 때까지 앱을 닫지 마세요.

자동 분석이 끝나면 결과 확인 창에 인식된 마디 수, 페이지 수, 템포와 박자가 표시됩니다. ScoreCue가 필수 값을 읽지 못하면 직접 입력하는 화면이 나타납니다.

## 결과에서 먼저 확인할 네 가지

| 항목 | 확인할 내용 | 잘못되었을 때 |
|---|---|---|
| 마디 수 | 악보의 실제 전체 마디와 대략 맞는가 | 저장하고 편집에서 누락된 경계는 나누고, 중복 경계는 합치기 |
| 페이지 수 | PDF의 실제 악보 페이지 수와 같은가 | 표지·빈 페이지·다른 곡이 함께 들어 있는지 원본 확인 |
| 템포 | 첫 템포 지시와 기준 음표가 같은가 | 곡 진행 편집에서 `♩=` 수정 |
| 박자 | 3/4, 4/4, 6/8 등 실제 박자인가 | 올바른 박자를 입력하고 중간 변경 지점도 편집에서 확인 |

ScoreCue가 박자표나 템포를 읽지 못하면 <strong>필수 정보 입력</strong>이 나타납니다. 이 값은 마디 시간, 카운트인과 자동 넘김 계산에 사용되므로 실제 악보와 같게 지정하세요.

## 자동 분석이 틀릴 수 있는 대표적인 경우

### 파일명·제목·페이지 번호가 악보 첫 줄과 가까운 경우

PDF를 만들 때 <strong>PDF 파일명이 악보 헤더 부분에 붙어 있거나</strong>, 제목·작곡가·페이지 번호가 악보 첫 줄과 지나치게 가까우면 다음과 같은 오인식이 생길 수 있습니다.

- 파일명이나 제목 속 숫자를 BPM 또는 박자 숫자로 판단
- 페이지 번호를 템포 숫자로 판단
- 제목의 세로획, 표의 선, 장식선을 마디선으로 판단
- 헤더와 첫 번째 보표 사이를 별도 영역이나 첫 마디로 잘못 판단
- 실제 첫 마디의 시작 위치를 놓쳐 첫 마디가 잘리거나 앞 영역과 합쳐짐

가능하면 PDF를 내보낼 때 <strong>페이지에 파일명 인쇄</strong> 같은 옵션을 끄고, 제목과 첫 보표 사이에 충분한 여백을 두세요. 이미 만들어진 PDF라면 자동 분석 후 첫 페이지의 헤더와 첫 줄을 가장 먼저 확인합니다.

### 마디선과 음표가 혼동되는 경우

- 흐리거나 끊긴 마디선을 놓쳐 실제 두 마디를 하나로 합침
- 음표 기둥, 긴 이음선, 가사 구분선 또는 표의 세로선을 마디선으로 판단해 한 마디를 둘로 나눔
- 두꺼운 겹세로줄이나 반복 기호를 여러 경계로 판단
- 페이지 가장자리에서 잘린 마디선이나 줄바꿈 마디를 놓침

### 진행 기호가 특수한 모양인 경우

- 도돌이표 점이 흐리거나 음표와 겹쳐 반복 시작·끝을 놓침
- 1·2번 엔딩 괄호가 여러 줄에 걸치거나 보표와 너무 가까워 범위를 잘못 판단
- Segno·Coda가 장식적인 글꼴이거나 작은 크기여서 일반 기호로 판단
- `D.C.`, `D.S.`, `Fine`, `To Coda` 문구가 다른 글자와 붙어 있거나 페이지 머리말·꼬리말에 가까워 놓침
- `rit.`, `accel.`, `a tempo` 문구가 가사나 연주 지시와 섞여 템포 변화 범위를 정확히 정하지 못함

### 원본 품질과 악보 형식이 복잡한 경우

- 손으로 쓴 악보, 낮은 해상도, 기울어진 스캔, 그림자나 얼룩이 있는 PDF
- 여러 악기가 동시에 표시되는 총보 또는 보표 연결이 복잡한 악보
- 자유 템포, 마디선 없는 구간, 긴 페르마타, 낭독 구간이 많은 곡
- 한 PDF에 표지, 여러 곡, 설명 페이지 또는 서로 다른 판형이 섞인 경우

## 분석 정확도를 높이는 PDF 준비

- 가능하면 원본 악보 프로그램에서 직접 PDF로 내보냅니다.
- 페이지에 파일명, 경로, 날짜를 덧붙이는 출력 옵션을 끕니다.
- 제목과 첫 보표, 페이지 번호와 악보 사이에 여백을 둡니다.
- 스캔본은 수평을 맞추고 그림자와 빈 테두리를 줄입니다.
- 마디선과 반복 기호가 잘리지 않도록 페이지 가장자리를 확인합니다.
- 표지나 설명 페이지는 가능하면 악보 PDF와 분리합니다.

## 저장할 때의 권장 선택

- **저장하고 편집 — 권장**: 마디 경계, 반복, 템포 변화와 진행 요약을 바로 검토합니다.
- **악보 진행 저장**: 단순한 악보를 우선 저장하되, 공연 전에 곡 진행 편집과 실제 재생으로 다시 확인합니다.
- **취소**: 원본 PDF를 정리하거나 직접 탭 방식으로 진행을 만들 때 선택합니다.

## 자동 분석 후 필수 검토 목록

1. 첫 페이지의 파일명·제목·페이지 번호가 마디나 템포로 잡히지 않았는지 확인합니다.
2. 각 줄의 첫 마디와 마지막 마디가 빠지지 않았는지 확인합니다.
3. 페이지 경계 전후의 마디가 잘못 합쳐지지 않았는지 확인합니다.
4. 도돌이표와 1·2번 엔딩의 범위를 실제 악보와 대조합니다.
5. D.C.·D.S., Segno, Fine, To Coda, Coda를 하나씩 확인합니다.
6. 첫 템포·박자와 곡 중간 변경 지점을 확인합니다.
7. rit., accel., a tempo와 페르마타의 시간을 확인합니다.
8. 진행 요약의 마디 순서를 따라가며 실제 연주 순서와 비교합니다.
9. 곡을 처음부터 끝까지 한 번 재생해 페이지 전환 시점을 확인합니다.

자세한 교정 방법과 모든 기호의 의미는 [곡 진행 편집 완전 안내]({{ '/ScoreCue/ko/guide/timing-edit/' | relative_url }})에서 확인할 수 있습니다.

<p class="tip">자동 분석이 여러 곳에서 계속 어긋나는 악보는 <a href="{{ '/ScoreCue/ko/guide/timing-manual/' | relative_url }}">직접 탭해서 진행 만들기</a>가 더 빠르고 정확할 수 있습니다.</p>

## 다시 분석할 때

악보 속성의 <strong>자동 생성</strong>은 기존 진행을 새 분석 결과로 바꿉니다. 직접 수정한 마디와 기호가 있다면 다시 분석하기 전에 현재 진행을 확인하세요.

<p class="warning">공연에서는 작은 오인식 하나도 반복 순서나 페이지 전환을 크게 바꿀 수 있습니다. 자동 인식 성공 메시지만 보고 바로 사용하지 말고, 반드시 수동 검토와 전체 재생 확인을 마치세요.</p>
