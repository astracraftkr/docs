## 자동 분석 시작

자동 분석이 끝나면 결과 확인 창에 인식된 마디 수, 페이지 수, 템포와 박자가 표시됩니다.

홈의 악보 카드에서 <strong>악보 진행 만들기</strong>를 누르거나, 뷰어의 상단 퀵 메뉴에서 <strong>악보 속성 → 자동 생성</strong>을 선택합니다. 분석이 끝날 때까지 앱을 닫지 마세요.

## 결과에서 확인할 네 가지

| 항목 | 확인할 내용 | 잘못되었을 때 |
|---|---|---|
| 마디 수 | 악보의 실제 전체 마디와 대략 맞는가 | 저장하고 편집에서 누락·중복 경계를 보정 |
| 페이지 수 | PDF 페이지 수와 같은가 | 원본 PDF와 가져온 파일 확인 |
| 템포 | 첫 템포 지시와 비슷한가 | 진행 편집에서 시작 BPM 수정 |
| 박자 | 3/4, 4/4 등 실제 박자인가 | 필수 정보 입력에서 올바른 박자 선택 |

ScoreCue가 박자표를 읽지 못하면 **필수 정보 입력**이 나타납니다. 이 값은 카운트인과 마디 시간 계산에 사용되므로 실제 악보와 같게 지정하세요.

## 저장과 편집 중 무엇을 선택할까

- **악보 진행 저장**: 분석 결과가 충분히 정확하고 바로 연주해 보고 싶을 때
- **저장하고 편집**: 마디 경계, 반복, 템포 변화 등을 확인하고 싶을 때
- **취소**: 다른 방법으로 진행을 만들거나 원본 PDF를 바꾸고 싶을 때

<p class="tip">먼저 저장한 뒤 실제로 재생해 보세요. 화면에서 보이는 마디 위치보다, 음악과 페이지 전환 시점이 자연스러운지가 더 중요합니다.</p>

## 자동 분석이 잘 맞지 않는 악보

다음과 같은 경우에는 [직접 탭해서 만들기]({{ '/ScoreCue/ko/guide/timing-manual/' | relative_url }})가 더 빠를 수 있습니다.

- 손으로 쓴 악보 또는 흐릿한 스캔
- 마디선이 페이지 가장자리에서 잘린 파일
- 여러 단이 복잡하게 연결된 총보
- 자유 템포, 긴 페르마타, 낭독 구간이 많은 곡
- 한 PDF 안에서 서로 다른 곡이나 박자가 자주 바뀌는 경우

## 다시 분석할 때

악보 속성의 <strong>자동 생성</strong>은 기존 진행을 새 분석 결과로 바꿉니다. 직접 수정한 값이 있다면 다시 분석하기 전에 현재 진행을 확인하세요.

<p class="warning">자동 분석은 출발점입니다. 공연에 쓰기 전에는 반드시 곡을 처음부터 끝까지 한 번 재생해 페이지 전환과 템포 변화를 확인하세요.</p>
