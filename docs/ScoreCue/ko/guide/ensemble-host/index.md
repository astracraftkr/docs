## 세션을 열기 전에

- 호스트 기기에서 로그인합니다. **세션 만들기는 로그인 필요**, 참여는 로그인 없이도 가능합니다.
- 가능하면 모든 기기를 같은 Wi-Fi에 연결합니다.
- Wi-Fi가 없다면 호스트의 모바일 핫스팟을 사용해도 됩니다. 인터넷 연결이 없어도 같은 로컬 네트워크라면 동작합니다.
- 사용할 악보 또는 셋리스트를 미리 열어 진행 정보를 확인합니다.

## 새 세션 만들기

<ol class="task-list">
  <li>홈의 <strong>합주 → 세션 만들기</strong>를 누릅니다.</li>
  <li>세션 이름을 입력합니다.</li>
  <li>필요하면 참여 암호와 밴드 멤버 전용 여부를 설정합니다.</li>
  <li>사용할 현재 곡 또는 셋리스트를 선택합니다.</li>
  <li>세션을 연 뒤 화면의 코드와 참여 방법을 멤버에게 알려 줍니다.</li>
</ol>

## 호스트가 제어하는 항목

- 시작과 정지
- 카운트인 마디 수
- 현재 곡과 다음 곡 전환
- 세션 BPM과 박자
- 시작 마디
- 참여자의 준비 상태
- 멤버의 시작·정지 허용 여부

참여자는 자신의 파트 악보를 보지만, 재생 시계와 곡 순서는 호스트를 따릅니다. 같은 마디 번호가 서로 다른 위치를 가리키지 않도록 각 파트의 악보 진행을 확인하세요.

## 악보 공유

세션에 있는 다른 사람이 없는 악보를 요청하면 PDF를 전송할 수 있습니다. 같은 Wi-Fi에서는 빠르게 전송되며, Bluetooth 연결만 사용할 때 큰 PDF는 오래 걸릴 수 있습니다. 앱이 빠른 전송을 위해 Wi-Fi Direct 연결을 제안하면 양쪽 기기에서 시스템 연결을 허용하세요.

<p class="tip">연습실에 공유기가 없다면 호스트가 핫스팟을 켜고 모든 멤버를 연결하세요. 인터넷 데이터가 없어도 Wi-Fi 속도로 악보를 주고받을 수 있습니다.</p>

## 무료 플랜의 30분 규칙

무료 사용자는 호스트인지 참여자인지와 관계없이 **하루에 한 번, 첫 세션에 들어간 시점부터 이어지는 30분 창**을 사용할 수 있습니다. 중간에 나갔다 다시 들어와도 타이머가 멈추거나 새로 시작되지 않습니다. 30분이 지나면 세션이 종료되고 Pro 안내가 표시됩니다.

<p class="note">Pro 참여자와 무료 호스트를 조합해 제한을 우회하지 못하도록 각 사용자의 플랜에 따라 자신의 기기에서 시간이 적용됩니다.</p>

## 세션 종료

연습이 끝나면 <strong>세션 종료</strong>를 누릅니다. 호스트가 종료하면 모든 참여자에게 종료 안내가 표시됩니다. 앱을 강제로 닫기보다 정상 종료하면 재연결 대기 상태가 남는 일을 줄일 수 있습니다.
