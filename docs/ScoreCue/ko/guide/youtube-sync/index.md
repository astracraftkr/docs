<p class="warning"><strong>YouTube 싱크에는 YouTube Premium으로 로그인된 계정을 사용하거나, 광고가 재생되지 않는 영상을 연결하세요.</strong> 광고가 나오면 영상 시간과 악보 진행이 달라져 정확한 싱크를 보장할 수 없습니다.</p>

## 연결하기 전에 확인하세요

- YouTube 플레이어가 <strong>Premium 계정으로 로그인</strong>되어 있는지 확인합니다.
- Premium을 사용하지 않는다면 실제 재생 시 광고가 나오지 않는 영상을 선택합니다.
- 영상이 공개 상태이며 연령·지역 제한 없이 현재 기기에서 재생되는지 확인합니다.
- 안정적인 네트워크에 연결하고, 공연에서는 영상이 처음부터 끝까지 정상 재생되는지 미리 시험합니다.

ScoreCue는 YouTube Premium 가입 여부나 로그인 상태, 특정 영상에 광고가 붙는지를 직접 확인할 수 없습니다. 첫 재생 때 표시되는 안내를 보고 현재 YouTube 계정 상태를 사용자가 직접 확인해야 합니다.

## YouTube 광고에 관하여

YouTube 광고의 종류, 노출 시점과 길이는 계정, 영상과 지역 등 YouTube의 정책에 따라 결정됩니다. ScoreCue는 YouTube 광고를 제거하거나 건너뛰게 할 수 없으며, 광고가 언제 끝날지 예측하거나 Premium 상태를 판별할 수도 없습니다.

광고 중에는 YouTube 플레이어의 영상 시간이 음악 재생 시간과 다르게 움직이거나 멈출 수 있습니다. 이 경우 ScoreCue의 악보 진행과 영상이 일치하지 않는 것은 앱에서 보정할 수 있는 일반적인 시작 오차가 아닙니다.

<p class="note">광고가 나타났다면 광고 재생이 완전히 끝난 뒤 영상과 악보를 처음부터 다시 시작하세요. 광고 없는 재생을 확실하게 준비해야 하는 공연에서는 기기에 저장한 <a href="{{ '/ScoreCue/ko/guide/local-audio/' | relative_url }}">로컬 오디오</a> 사용을 권장합니다.</p>

## YouTube 주소 연결

<ol class="task-list">
  <li>악보를 열고 빈 곳을 탭해 상단 퀵 메뉴를 표시합니다.</li>
  <li>조절 아이콘의 <strong>악보 속성</strong>을 엽니다.</li>
  <li><strong>YouTube 주소</strong>에 공유 링크 또는 영상 주소를 붙여 넣습니다.</li>
  <li>패널을 닫고 하단 추가 컨트롤에서 <strong>오디오 싱크 → YouTube</strong>를 선택합니다.</li>
  <li>Premium 로그인 여부 안내가 나타나면 현재 YouTube 계정 상태를 확인합니다.</li>
</ol>

일반 `youtube.com/watch` 주소와 짧은 `youtu.be` 공유 주소를 사용할 수 있습니다. 주소가 올바르지 않으면 입력란에 오류 안내가 표시됩니다.

## 시작 위치 맞추기

영상은 시작하자마자 음악이 나오지 않는 경우가 많습니다. 설명, 무음, 자체 카운트가 있다면 악보의 첫 박과 영상의 실제 음악 시작점을 맞춰야 합니다.

1. 광고가 없는 상태에서 영상을 재생합니다.
2. YouTube 플레이어에서 음악의 첫 박 직전으로 이동합니다.
3. 악보 재생을 시작해 첫 마디와 영상이 맞는지 듣습니다.
4. 영상이 늦으면 YouTube 시작 위치를 앞당기고, 빠르면 늦춥니다.
5. 처음 4~8마디를 반복해 오차가 가장 작은 값을 찾습니다.

<p class="tip">처음부터 완벽하게 맞추려 하지 말고 0.1~0.2초 단위로 조정하세요. Bluetooth 출력 지연이 있다면 영상 시작값과 별도로 전역 싱크 지연을 보정합니다.</p>

## 영상은 맞는데 뒤로 갈수록 어긋날 때

광고나 버퍼링이 없었다면 시작점 문제가 아니라 악보 진행의 BPM 또는 템포 변화가 영상과 다른 경우일 수 있습니다.

- 전체가 일정한 비율로 벌어진다면 기본 연주 속도와 첫 BPM을 확인합니다.
- 특정 지점부터 어긋나면 [곡 진행 편집]({{ '/ScoreCue/ko/guide/timing-edit/' | relative_url }})에서 중간 템포와 박자 변화를 확인합니다.
- 원곡이 자유 템포라면 YouTube를 들으며 직접 탭 기록을 만드는 편이 정확합니다.
- 영상이 잠시 멈췄다면 네트워크 버퍼링 또는 광고 가능성을 먼저 확인합니다.

## 재생되지 않거나 싱크가 갑자기 깨질 때

- 기기가 인터넷에 연결되어 있는지 확인합니다.
- 영상이 비공개, 삭제, 연령 제한 또는 지역 제한 상태인지 확인합니다.
- YouTube 계정이 Premium으로 로그인되어 있는지 다시 확인합니다.
- 광고 또는 버퍼링이 끝난 뒤 악보와 영상을 처음부터 다시 시작합니다.
- 같은 문제가 반복되면 광고가 없는 다른 영상이나 로컬 오디오를 사용합니다.
- 앱을 최신 버전으로 업데이트합니다.

<p class="warning"><strong>YouTube 광고는 YouTube의 정책을 따르며 ScoreCue에서 해결하거나 제어할 수 없습니다.</strong> 중요한 연습이나 공연 전에는 실제 사용할 계정과 영상으로 광고 없이 전체 재생되는지 반드시 확인하세요.</p>
