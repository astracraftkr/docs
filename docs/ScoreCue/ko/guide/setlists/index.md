## 새 셋리스트 만들기

<ol class="task-list">
  <li>홈의 <strong>셋리스트</strong> 영역에서 <strong>새 셋리스트</strong>를 누릅니다.</li>
  <li>공연명이나 연습일처럼 알아보기 쉬운 이름을 입력합니다.</li>
  <li>라이브러리에서 곡을 추가합니다.</li>
  <li>곡을 드래그해 실제 연주 순서로 정렬합니다.</li>
</ol>

## 공연 전에 확인할 것

- 모든 악보 PDF가 오프라인에서도 열리는지
- 각 곡에 악보 진행이 저장되어 있는지
- 기본 연주 속도와 카운트인이 곡마다 맞는지
- YouTube가 필요한 곡은 네트워크가 안정적인지
- 페달로 다음 곡과 첫 페이지를 문제없이 열 수 있는지

## 자동 다음 곡

설정의 <strong>연주 → 셋리스트 자동 다음 곡</strong>을 켜면 현재 곡의 진행이 끝났을 때 다음 곡으로 이동할 수 있습니다. 공연 성격에 따라 다음 옵션을 선택하세요.

- 곡 사이에 멘트나 튜닝 시간이 없다면 자동 이동을 켭니다.
- 곡 사이 준비가 필요하면 끄고 직접 다음 곡을 엽니다.

<p class="warning">자동 다음 곡을 사용할 때는 마지막 마디와 곡 종료 시간이 정확해야 합니다. 리허설에서 마지막 음이 잘리지 않는지 확인하세요.</p>

## 합주 세션에서 사용

호스트가 셋리스트를 세션에 사용하면 참여자의 각 악보를 호스트 곡과 연결할 수 있습니다. 같은 곡이라도 파트별 PDF 파일명은 달라도 됩니다. 참여자는 세션의 곡 매핑 화면에서 자신의 파트 악보를 지정합니다.

<p class="tip">공연용 셋리스트를 복제해 리허설용 순서를 따로 만들면 본 공연 순서를 실수로 바꾸는 일을 줄일 수 있습니다.</p>
