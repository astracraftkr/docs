## PDF가 목록에 보이지 않아요

1. 가져오기 화면에서 올바른 폴더가 선택되어 있는지 확인합니다.
2. 파일 확장자가 `.pdf`인지 확인합니다.
3. 폴더의 새로고침 버튼을 누릅니다.
4. Android 설정에서 ScoreCue의 파일 접근 권한을 확인합니다.
5. 시스템 선택기로 해당 PDF 한 개를 직접 열어 봅니다.

## 악보를 열 수 없어요

원본 PDF가 이동·삭제되었거나 폴더 접근 권한이 해제되었을 가능성이 큽니다. 파일 앱에서 원본을 확인한 뒤 ScoreCue에서 폴더를 다시 등록하고 파일을 다시 연결하세요.

## 자동 페이지 넘김이 시작되지 않아요

- 해당 악보에 **악보 진행**이 만들어져 있는지 확인합니다.
- 하단 컨트롤의 재생 버튼을 눌렀는지 확인합니다.
- 무료 자동 넘김 한도에 도달했다면 화면의 Pro 안내를 확인합니다.
- 진행 편집에서 시작과 끝 스텝이 비어 있지 않은지 확인합니다.

## 페이지가 너무 빠르거나 늦게 넘어가요

| 증상 | 조정할 항목 |
|---|---|
| 곡 전체가 같은 비율로 빠름·느림 | 기본 연주 속도 |
| 한 페이지 전환만 어긋남 | 진행 편집의 해당 경계 |
| 소리만 늦게 들림 | 오디오 출력·Bluetooth 지연 보정 |
| 항상 조금 더 일찍 페이지가 필요함 | 페이지 리드 |
| 뒤로 갈수록 점점 벌어짐 | BPM 또는 템포 변화 구간 |

## 카운트인이 들리지 않아요

- 설정 또는 곡별 카운트인이 **끔**인지 확인합니다.
- 미디어 음량과 현재 출력 장치를 확인합니다.
- 악보 진행에 BPM과 박자 정보가 있는지 확인합니다.
- 카운트인에만 메트로놈 옵션을 다시 껐다 켜 봅니다.

## YouTube가 재생되지 않거나 맞지 않아요

- 주소가 공개된 정상 영상인지 확인합니다.
- 광고, 버퍼링, 연령·지역 제한을 확인합니다.
- 시작만 어긋나면 YouTube 오프셋을 조절합니다.
- 뒤로 갈수록 어긋나면 악보 진행 템포를 수정하거나 영상을 들으며 직접 기록합니다.

## Bluetooth 페달이 반응하지 않아요

Android Bluetooth 설정에서 연결 상태를 확인하고, 다른 앱에서 키 입력을 시험한 뒤 ScoreCue에서 **학습**을 다시 실행합니다. 페달 모드를 바꿨다면 키 이름도 바뀌므로 다시 학습해야 합니다.

## 합주 세션이 보이지 않아요

1. 호스트 세션이 아직 열려 있는지 확인합니다.
2. 두 기기가 같은 Wi-Fi 또는 호스트 핫스팟에 연결되어 있는지 확인합니다.
3. 주변 기기·Bluetooth 권한을 허용합니다.
4. 세션 코드로 직접 참여합니다.
5. 앱 버전을 맞추고 두 기기에서 세션 화면을 다시 엽니다.

## 합주가 끊겼어요

앱은 약 30초 동안 자동 재연결을 시도합니다. 즉시 세션을 새로 만들지 말고 기다린 뒤, 실패하면 Wi-Fi 절전과 호스트 상태를 확인합니다. 무료 플랜의 30분 창이 끝난 경우에는 Pro 안내가 표시됩니다.

## 문의할 때 함께 보낼 정보

- 기기 제조사와 모델명
- Android 버전과 ScoreCue 앱 버전
- 문제가 생긴 메뉴와 순서
- 화면 캡처 또는 짧은 화면 녹화
- 합주 문제라면 호스트·참여자 수와 연결 방식(Wi-Fi, 핫스팟, Bluetooth)

문제가 계속되면 [support@astracraft.kr](mailto:support@astracraft.kr)로 보내 주세요. 악보 파일에는 저작권이 있을 수 있으므로 문제 재현에 꼭 필요한 경우에만 첨부하세요.
