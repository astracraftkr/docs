> **English:** [How to delete your ScoreCue account and data]({{ '/ScoreCue/en/delete-account/' | relative_url }})

이 페이지는 **ScoreCue**(Android · iOS/iPadOS, 앱 ID `kr.astracraft.scorecue`, 개발자 Astra Craft)
계정과 서버에 저장된 개인 데이터를 삭제하는 방법을 안내합니다. 로그인이나 앱 설치 없이 누구나
이 페이지를 볼 수 있으며, 아래 두 경로 중 하나로 삭제를 요청할 수 있습니다.

## 1. 앱에서 직접 삭제하기 (즉시 처리)

1. ScoreCue 앱을 엽니다.
2. **설정** 화면으로 이동합니다.
3. **계정** 항목에서 **계정 삭제**를 누릅니다.
4. 삭제 범위 안내를 읽고 **계속** → **영구 삭제**를 누릅니다.

확인을 누르면 서버에서 계정과 아래 3항의 데이터가 **즉시 영구 삭제**되며, 되돌릴 수 없습니다.
보안을 위해 최근 로그인 기록이 오래된 경우 다시 로그인한 뒤 진행하라는 안내가 나올 수 있습니다.

> **밴드를 소유하고 있다면 먼저 정리해야 합니다.** 남은 멤버가 밴드에 갇히지 않도록, 소유한 밴드를
> 삭제하거나 다른 멤버에게 소유권을 넘긴 뒤 계정 삭제를 진행하세요. 정리하지 않으면 앱이 삭제를
> 거부하고 그 사실을 안내합니다.

## 2. 앱 없이 이메일로 요청하기

앱을 이미 삭제했거나 앱에 접근할 수 없는 경우, 아래 주소로 요청하시면 저희가 대신 처리합니다.

- **받는 사람**: <a href="mailto:support@astracraft.kr?subject=ScoreCue%20%EA%B3%84%EC%A0%95%20%EC%82%AD%EC%A0%9C%20%EC%9A%94%EC%B2%AD">support@astracraft.kr</a>
- **제목**: `ScoreCue 계정 삭제 요청`
- **본문에 적을 것**: 로그인에 사용한 이메일 주소(Apple 로그인에서 이메일 가리기를 선택했다면 Apple이
  발급한 전달용 주소), 그리고 계정 전체 삭제인지 일부 데이터 삭제인지.

본인 확인 후 **접수일로부터 30일 이내**에 처리하고 결과를 회신합니다. 요청 사실과 처리 결과를 알리기
위해 회신용으로만 그 이메일 주소를 사용하며, 처리 후 요청 기록은 파기합니다.

## 3. 삭제되는 데이터

| 항목 | 저장 위치 |
|---|---|
| 계정 식별 정보(사용자 고유 ID, 이메일, 표시 이름, 프로필 사진 URL) | Firebase Authentication |
| 유료 권한 상태(권한 종류, 활성 여부, 만료일, 상품 식별자) | Cloud Firestore |
| 기기 활성화 기록 | Cloud Firestore |
| 모든 밴드에서의 본인 멤버 기록과 가입 요청 | Cloud Firestore |
| 본인이 작성한 일정 참석 응답(RSVP)과 가능일 투표 | Cloud Firestore |

**기기 안에만 저장되는 데이터**(악보 PDF, 필기, 재생 타이밍, 앱 설정, 메트로놈 프리셋)는 서버로
전송된 적이 없으므로 계정 삭제 대상이 아닙니다. 앱을 삭제하거나 운영체제 설정에서 앱 데이터를 지우면
함께 삭제됩니다. 이용자가 직접 다른 위치로 내보낸 백업 파일과 원본 PDF는 그 위치에 그대로 남습니다.

## 4. 삭제 후에도 남는 데이터와 보관 기간

| 항목 | 보관 기간 | 이유 |
|---|---|---|
| 스토어·RevenueCat의 구매·결제 기록 | 각 사업자의 정책과 관련 법령상 거래 기록 보존 의무 기간 | 구매 복원·환불·회계 대응 |
| 사용 통계(Firebase Analytics) | 최대 14개월 후 자동 삭제 | 앱 개선을 위한 통계 분석 |
| 오류 보고(Firebase Crashlytics) | Google 정책에 따라 통상 90일 이내 자동 삭제 | 결함 수정 |
| 밴드에 남긴 공지·공유 셋리스트 등 밴드 공동 기록 | 해당 밴드가 유지되는 동안 | 남은 멤버의 밴드 운영 연속성 |

통계·오류 보고는 계정과 분리된 앱 인스턴스 식별자로 수집되며, 원하시면 2항의 이메일로 그 데이터의
삭제도 함께 요청할 수 있습니다.

## 5. 계정은 유지하고 일부 데이터만 삭제하기

계정을 지우지 않고도 다음을 개별적으로 지울 수 있습니다.

- **밴드 데이터**: 앱의 밴드 화면에서 **밴드 탈퇴**를 하면 그 밴드에서의 본인 멤버 기록과 참석 응답·투표가
  삭제됩니다. 소유한 밴드는 밴드 설정에서 삭제할 수 있습니다.
- **기기 내 데이터**: 앱 안에서 악보·필기·타이밍을 개별 삭제하거나, 운영체제 설정에서 앱 데이터를
  지우면 한 번에 삭제됩니다.
- **사용 통계·오류 보고**: 2항의 이메일로 요청하시면 해당 데이터를 삭제합니다.
- **로그아웃**: 설정 화면에서 로그아웃하면 서버 연동이 중단되고 앱은 무료 범위로 동작합니다. 로그아웃은
  삭제가 아니며, 계정과 서버 데이터는 그대로 유지됩니다.
